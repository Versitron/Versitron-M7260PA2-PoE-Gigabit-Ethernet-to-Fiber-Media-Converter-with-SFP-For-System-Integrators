# Versitron M7260PA2 | PoE+ Gigabit Ethernet to Fiber Media Converter with SFP For System Integrator

The Versitron M7260PA2 is a Gigabit PoE+ media converter designed for system integrators who need to extend Ethernet networks over fiber while simultaneously powering remote devices. It converts 10/100/1000Base-T copper Ethernet to 1000Base-X fiber through an SFP slot, enabling flexible fiber deployment based on distance and application requirements.
